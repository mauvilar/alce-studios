# ALCE STUDIOS — Landing Page

One-page site for [@alce_studios](https://www.instagram.com/alce_studios/), an audiovisual
production studio based in Cancún (music videos, commercials, weddings, brand content).

Built with Vite + React + Tailwind CSS v4 + GSAP/ScrollTrigger. All copy, media, logo, and
client credits are sourced from the studio's real Instagram content.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

Edit `src/content.js` to update copy, services, showcase items, featured cases, or the
client/artist credits list. Media assets live in `public/media/`.
